# 2.2.3 Odstranění ε-přechodů

<a id="def-epsilon-prechod"></a>
!!! Definition "[Definice ($\varepsilon$-přechod)](#def-epsilon-prechod)"

    ### $\varepsilon$-přechod {#def-epsilon-prechod}

    **$\varepsilon$-přechod** je přechod, který může automat provést pro libovolný symbol na vstupu, přičemž při použití tohoto přechodu se ze vstupu **žádný symbol nečte** (čtecí hlava se neposouvá).

<a id="def-epsilon-closure"></a>
!!! Definition "[Definice ($\varepsilon$-closure)](#def-epsilon-closure)"

    ### $\varepsilon$-closure {#def-epsilon-closure}

    Funkce $\varepsilon\text{-Closure} : Q \to 2^Q$ pro konečný automat $M = (Q, \Sigma, \delta, q_0, F)$ je definována takto:

    $$
    \varepsilon\text{-Closure}(q) = \{p \in Q \mid (q, \varepsilon) \vdash_M^* (p, \varepsilon)\}
    $$

    Pro daný stav $q$ tedy vrací množinu všech stavů, které jsou z něj dosažitelné čistě pomocí posloupnosti $\varepsilon$-přechodů (včetně stavu $q$ samotného).

<a id="algo-remove-epsilon"></a>
!!! Algorithm "[Odstranění $\varepsilon$-přechodů](#algo-remove-epsilon)"

    ### Odstranění $\varepsilon$-přechodů {#algo-remove-epsilon}

    **Vstup:** NKA s $\varepsilon$-přechody $M = (Q, \Sigma, \delta, q_0, F)$.  
    **Výstup:** NKA bez $\varepsilon$-přechodů $M' = (Q, \Sigma, \delta', q_0, F')$ takový, že $L(M') = L(M)$.

    1. Pro každý stav $q \in Q$ vypočteme $\varepsilon\text{-Closure}(q)$.
    2. Novou přechodovou funkci $\delta'$ definujeme pro všechna $q \in Q$ a $a \in \Sigma$ jako:

    $$
    \delta'(q, a) = \bigcup_{p \in \varepsilon\text{-Closure}(q)} \delta(p, a)
    $$

    3. Novou množinu koncových stavů $F'$ tvoří stavy, jejichž $\varepsilon$-uzávěr obsahuje alespoň jeden původní koncový stav:

    $$
    F' = \{q \in Q \mid \varepsilon\text{-Closure}(q) \cap F \neq \emptyset\}
    $$
