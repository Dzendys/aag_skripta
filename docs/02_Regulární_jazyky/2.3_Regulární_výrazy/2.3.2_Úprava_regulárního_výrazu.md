# 2.3.2 Úprava regulárního výrazu

Úpravou (zjednodušením) regulárního výrazu máme na mysli převedení daného regulárního na jednodušší (kratší) při zachování hodnoty výrazu. Využít můžeme následujících vztahů:

<a id="theorem-rv-simplification"></a>
!!! Theorem "[Vlastnosti a věty pro úpravu RV](#theorem-rv-simplification)"

    ### Vlastnosti a věty pro úpravu RV {#theorem-rv-simplification}

    Nechť $x, y, z$ jsou regulární výrazy. Pak platí následující **základní vlastnosti (identity)**:

    $$
    \begin{aligned}
    P_1 &: x + (y + z) = (x + y) + z && \text{(asociativita sjednocení)} \\
    P_2 &: x + y = y + x && \text{(komutativita sjednocení)} \\
    P_3 &: x + \emptyset = x && \text{($\emptyset$ je neutrální prvek pro sjednocení)} \\
    P_4 &: x + x = x && \text{(idempotence sjednocení)} \\
    P_5 &: x \cdot (y \cdot z) = (x \cdot y) \cdot z && \text{(asociativita zřetězení)} \\
    P_6 &: \varepsilon x = x \varepsilon = x && \text{($\varepsilon$ je neutrální prvek pro zřetězení)} \\
    P_7 &: \emptyset x = x \emptyset = \emptyset && \text{($\emptyset$ je nulový prvek pro zřetězení)} \\
    P_8 &: x \cdot (y + z) = x \cdot y + x \cdot z && \text{(distributivita zleva)} \\
    P_9 &: (x + y) \cdot z = x \cdot z + y \cdot z && \text{(distributivita zprava)} \\
    P_{10} &: x^* = \varepsilon + x^* x \\
    P_{11} &: x^* = (\varepsilon + x)^*
    \end{aligned}
    $$

    Dále platí následující **věty v teorii regulárních výrazů**:

    $$
    \begin{aligned}
    V_1 &: \emptyset^* = \varepsilon \\
    V_2 &: x^* + x = x^* \\
    V_3 &: (x^*)^* = x^* \\
    V_4 &: (x + y)^* = (x^* y^*)^* \\
    V_5 &: x^* y = y + x^* x y \\
    V_6 &: x^* y = y + x x^* y \\
    V_7 &: x^* y = (x^n)^* \cdot (y + xy + x^2 y + \dots + x^{n-1} y) \\
    V_8 &: x x^* = x^* \quad (\text{pokud } \varepsilon \in L(x)) \\
    V_9 &: (x y)^* x = x (y x)^* \\
    V_{10} &: (x + y)^* = (x^* + y^*)^*
    \end{aligned}
    $$
