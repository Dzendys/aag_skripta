# 2.3.3 Regulární rovnice

Regulární rovnice dělíme na dva typy ($\alpha, \beta$ jsou známé RV, $x$ je neznámý RV):

<a id="def-regularni-rovnice"></a>
!!! Theorem "[Ardenova věta (Regulární rovnice)](#def-regularni-rovnice)"

    ### Ardenova věta (Regulární rovnice) {#def-regularni-rovnice}

    Nechť $x, \alpha, \beta$ jsou regulární výrazy. Pak platí:

    *   **Levá regulární rovnice** $x = x\alpha + \beta$ má řešení $x = \beta\alpha^*$.
    *   **Pravá regulární rovnice** $x = \alpha x + \beta$ má řešení $x = \alpha^*\beta$.

!!! Warning "Pozor na správné řešení!"

    *   $x = \alpha x \implies x = \alpha x + \emptyset \implies x = \emptyset$ (pokud $\varepsilon \notin h(\alpha)$). Častá chyba je $x = \alpha^*$.
    *   $x = \alpha x + \varepsilon \implies x = \alpha^*$.
